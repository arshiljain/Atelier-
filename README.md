# Atelier

> Free & Open Source Kinetic UI & Motion Component Library

Atelier is a 100% free and open-source UI and kinetic motion component library. Designed for modern web applications, motion graphics, and interactive design systems.

---

## ✨ Features

- **Kinetic Blocks & Components**: High-performance interactive UI blocks with generative motion, typography distortions, and physics presets.
- **Modern Design System**: Modular design tokens, CSS variables, dark and light modes, and seamless Tailwind CSS integration.
- **Figma to Code**: Direct translation from Figma designs into clean React and Tailwind components.
- **Component Manifests**: Downloadable JSON component manifests and ready-to-copy code blocks for instant workflow integration.
- **Zero Lock-In**: 100% MIT Licensed for personal and commercial projects.

---

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)

### Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/arshiljain/Atelier.git
   cd Atelier
   ```

2. Start the local server:
   ```bash
   node serve.js
   ```

3. Open your browser and navigate to:
   - **Home**: `http://localhost:3000/`
   - **Blocks**: `http://localhost:3000/blocks`
   - **Product**: `http://localhost:3000/product`
   - **Templates**: `http://localhost:3000/templates`
   - **Pricing**: `http://localhost:3000/pricing`
   - **Docs**: `http://localhost:3000/docs`
